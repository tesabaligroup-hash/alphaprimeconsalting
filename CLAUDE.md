# Alpha Prime — Telegram Mini App

Владелец: Tesa (Alpha Prime Consulting, Бали). Общение и тексты интерфейса — на русском.

## Что это
Личный кабинет клиента + партнёрская программа в Telegram. ТЗ: модули 3 и 4 «ТЗ Alpha Prime v2.1» + «ТЗ Партнёрская программа» (11.11.2026).
Макеты согласованы на канвасе Design «Alpha Prime — Telegram-приложение (экраны)». Стиль — белый/золотой:
ink #1C1A16, gold #C9A24B, gold-ink #7A5C17, cream #FBF7EC; заголовки Cormorant Garamond, текст и все цифры — Manrope.

## Стек
- `backend/` — FastAPI + SQLAlchemy 2 (PostgreSQL, в тестах SQLite), aiogram 3 (бот в `app/worker.py`), Jinja-админка `/admin`.
- `frontend/` — React + Vite + TS, Mini App. Сборка кладётся в образ и отдаётся FastAPI.
- Kommo: `app/kommo/real.py` (API v4), `mock.py` (тестовые данные), `mapping.py` (поля/этапы — пометки ПРОВЕРИТЬ).
- Выкладка: push в `main` → GitHub Actions (тесты + сборка) → ssh на сервер → `docker compose up -d --build`.

## Правила, которые нельзя нарушать
- Партнёр видит только имя/ник друга, статус и свою сумму. Никаких услуг, цен, маржи, процентов, паспортных данных.
- Вознаграждение — только за друзей, которые заказали И оплатили услугу. Уровней максимум 2.
- Формулы выплат: `app/partner_rules.py`, тарифы: `app/tariffs.py` — тесты сверяют их с таблицей тарифов (`tests/data/tariffs_expected.json`).
- Кодовое слово: ≥6 символов, буквы/цифры, не общее слово (стоп-лист в коде + в админке), уникальное; меняет только менеджер.
- Этапы клиента (12.11.2026 — 3 шага): Оплата → Подача в иммиграцию (у не-визовых услуг «В работе») → Готово.
- Поле «Партнёр» приложение заполняет само для закреплённых клиентов (12 мес.), «Нет»/«Другое» от менеджера не трогает. Бот в группе менеджеров: /kod СЛОВО, /proverka; по понедельникам — список недозаполненных сделок.
- Виджеты Telegram (`app/widgets.py`): /visa, /events, /partner в личном чате с ботом; обновляются раз в час; «Хочу пойти» → заявка как у новости. Партнёрский виджет — без услуг и цен.
- В каталоге нет школьных и пенсионных KITAS (`in_catalog=False`).
- Секреты только в `.env` на сервере, не в репозитории.

## Проверка перед коммитом
```bash
cd backend && python -m pytest -q
cd frontend && npm run build
```
